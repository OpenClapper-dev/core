# OpenClapper

An open-source way to organise film productions, built together with the people who do the job.
The project, its plan and the two forms that start it are on [openclapper.org](https://openclapper.org).

**What is in this repository is experimental.** It is the maintainer's own tooling for his hobby
shoots, shaped by one person's projects; it is not a release, and it is not what the industry needs.
The proper alpha gets defined with the community first (the plan on the page), and is built from that.

The [docs](docs/README.md) describe what the code does today. [Self-hosting](docs/self-hosting.md)
explains how to run it on your own Cloudflare account, for the curious, without any promise that things
work or stay compatible: during the experimental phase anything may change or break.
